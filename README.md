# Hotel Management System (Java - NetBeans)

This repository contains a Java Swing **Hotel Management System** project.  
It includes:
- Reverse engineering output (UML Class Diagram)
- Refactored source code
- Report document

---

## Project Structure
- `src/` : Java source code
- `lib/` : Required external libraries (JARs)
- `nbproject/` : NetBeans project configuration
- `res/` : Resources (images, icons, etc.)
- `submission/` :
  - `submission/UML/` : UML class diagram image (exported)
  - `submission/report/` : Report document (Word)
- `build.xml` : Ant build script
- `hotel.sqlite` : SQLite database file (if included)

---

## Requirements
- Apache NetBeans (recommended)
- JDK 8 or later (recommended: JDK 8 / 11 / 17)
- SQLite JDBC driver (already included in `lib/`)

---

## How to Run (NetBeans)
1. Open NetBeans
2. **File → Open Project**
3. Select the project folder and open it
4. If NetBeans shows missing libraries:
   - Right click the project → **Properties**
   - Go to **Libraries**
   - Remove broken references and re-add JAR files from the `lib/` folder
5. Run the project:
   - Right click project → **Run**
